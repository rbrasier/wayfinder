# Routes compiled before Playwright starts (run by warm-routes.sh in CI).
#
# Each one is a route a spec has been seen paying a first-request `next dev`
# compile for, inside a wait shorter than the compile. `:id` stands in for any
# dynamic segment. src/e2e-warm-routes.test.ts checks every line still resolves
# to a page or route handler, so a renamed route fails there, not in CI.
#
# Not listed: /login and /register (the middleware redirects a signed-in request
# away before they compile), and /api/sessions/:id/events (an SSE stream that
# never ends a response, so it cannot be awaited here).
